# Railway Environment Variables Configuration

## Required Environment Variables

Set these in your Railway dashboard (Settings → Variables):

### Database Configuration
```
DATABASE_URL=postgresql://username:password@host:port/database
# Railway automatically provides this when you add PostgreSQL service
```

### API Configuration
```
API_HOST=0.0.0.0
API_PORT=8000
API_ENV=production
```

### Security
```
SECRET_KEY=your-super-secret-key-here
JWT_SECRET=your-jwt-secret-key-here
CORS_ORIGINS=https://six3agency.com,https://www.six3agency.com
```

### AI Service API Keys
```
OPENAI_API_KEY=your-openai-api-key
ANTHROPIC_API_KEY=your-anthropic-api-key
```

### External Services
```
# n8n Integration
N8N_WEBHOOK_BASE_URL=https://workflows.six3agency.com/webhook
N8N_API_KEY=your-n8n-api-key

# Email Service (if using)
SENDGRID_API_KEY=your-sendgrid-key
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your-email@gmail.com
SMTP_PASSWORD=your-app-password
```

### File Storage
```
# For work products storage
STORAGE_TYPE=s3
AWS_ACCESS_KEY_ID=your-aws-key
AWS_SECRET_ACCESS_KEY=your-aws-secret
AWS_BUCKET_NAME=six3-agency-storage
AWS_REGION=us-east-1
```

## Railway-Specific Variables

Railway automatically provides:
```
PORT=8000  # Railway sets this automatically
RAILWAY_ENVIRONMENT=production
RAILWAY_PROJECT_ID=auto-generated
RAILWAY_SERVICE_ID=auto-generated
```

## Setup Instructions

1. **Add PostgreSQL Service in Railway:**
   - Go to your Railway project
   - Click "New" → "Database" → "PostgreSQL"
   - Railway automatically creates `DATABASE_URL`

2. **Set Environment Variables:**
   - Go to Settings → Variables
   - Add each variable above with your actual values
   - Variables are automatically injected into your application

3. **Deploy:**
   - Connect your GitHub repository
   - Railway automatically builds and deploys
   - Check logs for any missing variables

## Development vs Production

### Development (.env file):
```
DATABASE_URL=postgresql://localhost:5432/six3_agency_dev
API_ENV=development
DEBUG=true
```

### Production (Railway Variables):
```
DATABASE_URL=(auto-generated by Railway)
API_ENV=production
DEBUG=false
```
