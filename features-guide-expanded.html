🎯 How to Get Started
Step 1: Set up your environment by installing Docker, PostgreSQL, and Redis
Step 2: Configure your API keys (Mailgun for emails, Attio for CRM, OpenAI/HuggingFace for AI)
Step 3: Deploy the agent service and workflow engine using docker-compose
Step 4: Import pre-built workflows from the /workflows directory
Step 5: Access the control panel at /control-panel-full.html to monitor all agents

💡 Pro Tip: Start with Phase 1 agents (Prospect Agent and FAQ Chatbot) to understand the system, then gradually enable Phase 2 and Phase 3 agents as you get comfortable with the platform.

1. Prospect Agent

Purpose: Automatically qualify leads using sentiment analysis and behavioral signals.

How to Use the Prospect Agent
Via API:
curl -X POST http://localhost:8000/phase1/qualify-lead \ -H "Content-Type: application/json" \ -d '{ "lead_name": "John Smith", "lead_email": "john@acmecorp.com", "company": "Acme Corp", "industry": "Technology", "lead_message": "I need a solution for automating our sales process" }'
Expected Response:
{ "success": true, "qualification_score": 8.5, "qualification_status": "hot", "sentiment": { "label": "positive", "score": 0.92 }, "next_actions": [ "Schedule discovery call within 24 hours", "Send case studies in similar industry" ], "reasoning": "High intent signals, clear pain point, decision-maker" }
📝 Real-World Example

Scenario: You receive 100 inbound leads per day from your website contact form.

Without Prospect Agent: Sales team spends 2-3 hours manually reviewing each lead, missing hot leads that need immediate attention.

With Prospect Agent:

  • All 100 leads are qualified within 5 minutes
  • Hot leads (score 8+) are immediately routed to senior sales reps
  • Warm leads (score 6-7.9) are added to nurture campaigns
  • Cold leads (score <6) are archived or added to long-term campaigns
  • Result: 80% reduction in qualification time, 40% increase in conversion rates
💼 Use Cases
  • Website Lead Qualification: Automatically score all form submissions
  • Email Response Qualification: Analyze replies to outreach campaigns
  • Chat Qualification: Score leads from live chat conversations
  • Event Follow-up: Qualify attendees after webinars or conferences

Phase 3 agents are the "brain" of the system—they coordinate other agents, manage complex workflows, and provide intelligence for decision-making.

9. Orchestrator Agent

Purpose: Central coordinator that routes customer interactions to the appropriate agents based on journey stage, intent, and context.

How the Orchestrator Works

The Orchestrator manages 7 distinct journey stages:

1. AWARENESS: Prospect discovers your brand → Marketing Agent creates personalized content
2. CONSIDERATION: Prospect evaluates options → Research Agent provides comparisons, case studies
3. DECISION: Prospect ready to buy → Sales Agent handles objections, provides pricing
4. PURCHASE: Customer commits → Project Manager Agent initiates onboarding
5. ONBOARDING: New customer setup → Customer Success Agent guides implementation
6. ADOPTION: Customer uses product → Analytics Agent tracks usage, identifies issues
7. RETENTION: Ongoing relationship → Success Agent monitors health, identifies expansion opportunities
📝 Orchestration in Action

Scenario: Sarah visits your website and fills out a contact form.

  1. T+0 seconds: Form submitted → Webhook triggers Orchestrator Agent
  2. T+5 seconds: Orchestrator calls Prospect Agent to qualify → Score: 8.5 (Hot Lead)
  3. T+10 seconds: Orchestrator calls Sales Pitch Agent to personalize email
  4. T+15 seconds: Welcome email sent with personalized pitch
  5. T+30 seconds: Slack notification sent to sales rep with full context
  6. T+1 hour: Sarah replies asking about pricing
  7. T+1 hour, 5 seconds: Intent Classifier detects "pricing" intent
  8. T+1 hour, 10 seconds: Email Personalizer generates pricing response with case studies
  9. T+1 hour, 15 seconds: Response sent automatically
  10. T+2 hours: Sarah books a demo
  11. T+2 hours, 5 seconds: Calendar invitation sent, sales rep notified, prep materials generated

Result: From initial contact to demo booked in 2 hours, zero manual intervention. Sales rep only gets involved for the actual demo call.
