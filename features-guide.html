Quick Start Guide

1. Environment Setup

  • Clone repository: git clone https://github.com/Humasci/Instant-Agency
  • Copy environment variables: cp .env.example .env
  • Configure API keys (Mailgun, Attio, OpenAI, etc.)

2. Local Development

  • Install dependencies: pip install -r agents/requirements.txt
  • Start services: docker-compose up -d
  • Run agent service: python agents/main.py
  • Access dashboard: http://localhost:8000

3. Deploy to Production

  • Vercel: Connect GitHub repo and deploy
  • Railway: Import Docker Compose or Dockerfile
  • GCP: Follow guide in google_cloud_deployment.md
