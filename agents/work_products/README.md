# Agent Work Products Storage

This directory contains all work products generated by SIX3 Agency expert agents. Each agent maintains its own subdirectory with structured file organization.

## Storage Structure

### Directory Organization
```
work_products/
├── search_marketing/          # Search Marketing Expert outputs
├── ai_media/                  # AI Media Expert outputs  
├── ml_ai/                     # ML/AI Expert outputs
├── communications/            # Client Communication Manager outputs
├── project_management/        # AI Project Manager outputs
└── research/                  # Research Analyst outputs
```

### File Naming Convention
All files follow the pattern: `{work_product_type}_{client_id}_{date}_{version}.json`

Examples:
- `market_analysis_techflow_20241118_v1.json`
- `campaign_strategy_innovacorp_20241118_v2.json`
- `creative_brief_startup123_20241118_v1.json`

## Data Formats and Standards

### JSON Schema Structure
All work products follow a standardized JSON schema:

```json
{
  "metadata": {
    "work_product_id": "uuid",
    "work_product_type": "string",
    "client_id": "string", 
    "project_id": "string",
    "agent_name": "string",
    "agent_version": "string",
    "created_date": "iso_timestamp",
    "last_modified": "iso_timestamp",
    "version": "integer",
    "status": "active|archived|superseded",
    "file_size_bytes": "integer",
    "content_hash": "sha256"
  },
  "data": {
    // Agent-specific work product content
  },
  "relationships": {
    "depends_on": ["work_product_ids"],
    "related_to": ["work_product_ids"],
    "supersedes": "work_product_id"
  },
  "quality_assurance": {
    "reviewed_by": "string",
    "review_date": "iso_timestamp", 
    "quality_score": "integer 1-10",
    "validation_notes": "string"
  }
}
```

### Versioning Strategy
- **Version 1.0**: Initial creation
- **Version 1.1**: Minor updates/corrections
- **Version 2.0**: Major revisions/scope changes
- **Automatic Backup**: Previous versions retained for 30 days
- **Archive Policy**: Versions older than 1 year moved to cold storage

## Access Control and Security

### File Permissions
- **Agent Write**: Agents can create and update their own work products
- **Cross-Agent Read**: Agents can read work products from other agents for collaboration
- **Client Access**: Clients have read-only access to their own work products
- **Admin Access**: Full read/write access for system administrators

### Data Protection
- **Encryption**: All files encrypted at rest using AES-256
- **Access Logging**: All file access logged for audit purposes
- **Backup Strategy**: Daily incremental backups with 30-day retention
- **Disaster Recovery**: Geographic redundancy with 4-hour RTO

### Compliance Features
- **Data Retention**: Configurable retention policies per client
- **Right to Deletion**: Support for GDPR data deletion requests
- **Audit Trail**: Complete history of all file modifications
- **Export Capability**: Client data export in standard formats

## Integration with Database

### Work Product Tracking
Each work product file is tracked in the `agent_work_products` database table with:
- File path and metadata
- Version history
- Access tracking
- Quality metrics
- Relationship mapping

### Automated Synchronization
- **File Creation**: Automatic database entry creation
- **Modification Tracking**: Last modified timestamps synchronized
- **Integrity Checking**: Periodic hash validation
- **Cleanup Processes**: Automated cleanup of orphaned files

## Usage Examples

### Creating a Work Product
```python
# Agent creates work product
work_product = {
    "work_product_type": "market_analysis",
    "client_id": "techflow_001",
    "agent": "search_marketing_expert",
    "data": analysis_results,
    "metadata": consultation_context
}

# Save to file system
file_path = f"/work_products/search_marketing/techflow_001/market_analysis_{date}_v1.json"
save_work_product(work_product, file_path)

# Register in database
register_work_product(work_product, file_path)
```

### Retrieving Work Products
```python
# Get latest work product
latest_analysis = get_latest_work_product(
    client_id="techflow_001",
    agent_type="search_marketing_expert", 
    work_product_type="market_analysis"
)

# Get work product history
analysis_history = get_work_product_history(
    client_id="techflow_001",
    work_product_type="market_analysis"
)
```

### Cross-Agent Collaboration
```python
# Project Manager accessing other agent work
client_data = {
    "market_analysis": get_work_product("search_marketing_expert", "market_analysis"),
    "creative_brief": get_work_product("ai_media_expert", "creative_brief"),
    "technical_specs": get_work_product("ml_ai_expert", "technical_assessment")
}

# Create integrated project plan
project_plan = create_project_plan(client_data)
save_work_product(project_plan, project_plan_path)
```

This storage system ensures that all expert agent work is properly organized, tracked, and secured while enabling seamless collaboration and client service delivery.
